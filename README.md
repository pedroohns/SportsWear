# SportsWear

O **SportsWear** é um protótipo de loja virtual voltada à venda de camisas de futebol, desenvolvido como projeto de estudo para explorar os recursos e componentes oferecidos pelo **Bootstrap**.

O projeto apresenta uma interface simples, responsiva e organizada, seguindo a estrutura visual característica do framework.

## Sobre o projeto

O SportsWear foi desenvolvido com o objetivo de colocar em prática conceitos de construção de interfaces utilizando Bootstrap.

A proposta foi criar uma página de e-commerce simples como contexto para experimentar componentes, sistema de grid, responsividade e outros recursos oferecidos pelo framework.

A página simula uma loja especializada em camisas de futebol, apresentando produtos de diferentes clubes em uma interface inspirada em plataformas de comércio eletrônico.

## Funcionalidades e características

A implementação conta com:

- Interface responsiva;
- Alternância entre modo claro e modo escuro;
- Seção de apresentação da loja;
- Catálogo de produtos utilizando cards;
- Informações de preço e descrição dos produtos;
- Seção institucional;
- Formulário de contato;
- Navegação entre as principais seções da página.

## Tecnologias

As principais tecnologias utilizadas no projeto foram:

- HTML
- CSS
- JavaScript
- Bootstrap

## Objetivo de aprendizado

Este projeto foi desenvolvido principalmente como uma experiência prática com o **Bootstrap**, explorando a utilização do framework na construção rápida de interfaces responsivas.

O objetivo não foi desenvolver uma plataforma completa de e-commerce, mas compreender melhor a estrutura, os componentes e as possibilidades oferecidas pela ferramenta durante o desenvolvimento front-end.

## Status

🔵 **Projeto de estudo — concluído**

O SportsWear representa um exercício de desenvolvimento front-end e não possui back-end, banco de dados, sistema de pagamentos ou funcionalidades reais de comércio eletrônico.

Existe a possibilidade de, futuramente, o conceito ser revisitado em uma nova implementação desenvolvida sem Bootstrap, explorando uma identidade visual e uma arquitetura front-end próprias.
